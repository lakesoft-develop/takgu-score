# 탁구 스코어 (PWA)

아이폰·아이패드·갤럭시 폰·갤럭시 탭에서 같이 쓰는 탁구 점수판입니다. 앱스토어 없이 웹 주소로 열고 **홈 화면에 추가**하면 앱처럼 전체 화면으로 실행되고, 한 번 연 뒤에는 인터넷 없이도 열립니다.

## 기능 (공식 규칙 기준)

- 선수 쪽 화면을 탭하면 1점 추가, **되돌리기**로 한 단계씩 취소 (게임·매치 종료도 되돌릴 수 있음)
- 11점 선취, 10:10부터는 2점 차가 나야 승리 (듀스)
- 서브: 2점마다 교대, 10:10부터는 1점마다 교대. 서브권과 몇 번째 서브인지(1/2, 2/2) 표시
- 앞 게임에서 먼저 서브한 선수는 다음 게임에서 리시브 (첫 서브 자동 교대)
- 3게임(2선승) / 5게임(3선승) / 7게임(4선승) 선택
- 게임이 끝나면 좌우(엔드) 자동 교체, 마지막 게임은 한 선수가 5점에 도달할 때 한 번 더 교체
- 게임 포인트 / 매치 포인트 / 듀스 표시, 게임 기록
- 선수 이름 수정, 서브 바꾸기(첫 서브를 잘못 정했을 때), 좌우 수동 바꾸기, 새 매치
- 경기 중 화면 꺼짐 방지 (Wake Lock), 다크/라이트 모드, 득점 진동(안드로이드)
- 앱을 닫았다 열어도 진행 중인 경기가 그대로 남아 있음

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (화면·스타일·로직) |
| `manifest.webmanifest` | 홈 화면 설치 정보 (이름, 아이콘, 전체 화면) |
| `sw.js` | 오프라인 캐시 (서비스 워커) |
| `icons/` | 앱 아이콘 (192, 512, 마스커블 512, 애플 180) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 내보내게 함 |
| `screenshots/` | 기기별 확인 화면 (로컬에만 있고 저장소에는 올리지 않음) |

## 주소: https://lakesoft-develop.github.io/takgu-score/

저장소 [lakesoft-develop/takgu-score](https://github.com/lakesoft-develop/takgu-score)의 `main` 브랜치를 GitHub Pages로 내보냅니다. 오프라인 실행과 화면 꺼짐 방지는 HTTPS에서만 동작해서 HTTPS 주소가 필요합니다.

> 처음에는 Netlify에 올렸습니다. 하지만 무료 플랜에서는 숨길 수 없는 「Powered by Netlify」 배지가 오른쪽 아래 탭 영역을 가려서 GitHub Pages로 옮기고 Netlify 사이트는 지웠습니다(`screenshots/14-netlify-badge.png`).

## 설치 방법

### 아이폰 / 아이패드 (Safari)
1. Safari로 앱 주소를 엽니다.
2. **공유 버튼**을 누릅니다. 아이폰은 화면 아래, 아이패드는 주소창 오른쪽에 있습니다.
3. **홈 화면에 추가** → **추가**를 누릅니다.
4. 홈 화면의 「탁구 스코어」 아이콘으로 실행합니다.

> 화면 꺼짐 방지는 iOS 18.4 이상의 홈 화면 앱에서 동작합니다. 그보다 낮은 버전이면 설정 → 디스플레이 및 밝기 → 자동 잠금을 「안 함」으로 바꿔 주세요.

### 갤럭시 폰 / 갤럭시 탭
**Chrome**
1. Chrome으로 앱 주소를 엽니다.
2. 오른쪽 위 **⋮** → **홈 화면에 추가**(또는 **앱 설치**) → **설치**를 누릅니다.

**삼성 인터넷**
1. 삼성 인터넷으로 앱 주소를 엽니다.
2. 주소창의 **설치(⬇) 아이콘**을 누르거나, 아래 **메뉴(≡)** → **현재 페이지 추가** → **홈 화면**을 누릅니다.

앱 안의 **메뉴(⋯)**에도 기기에 맞는 설치 안내가 나옵니다.

## 사용 팁
- 기기를 탁구대 옆에 두고, 각 선수 쪽 절반을 탭하면 됩니다. 가로·세로 모두 됩니다.
- 실수로 두 번 탭해도 0.3초 안의 연속 탭은 한 번만 셉니다.
- 블루투스 키보드: ← → 득점, Z 되돌리기, Enter 다음 게임

## 수정 후 배포할 때
1. `sw.js`의 `VERSION`을 올립니다(`v1` → `v2`). 그래야 이미 설치한 기기에도 새 버전이 받아집니다. 새 버전은 앱을 한 번 열면 내려받고, 다음 실행부터 적용됩니다.
2. 커밋하고 `git push`하면 GitHub Pages가 1~2분 안에 새로 내보냅니다.
